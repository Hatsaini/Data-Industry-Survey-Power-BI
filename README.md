# Professional Survey Breakdown: Data Industry

## Overview
This Power BI dashboard analyzes responses from a global **Data Professional Survey (n = 630)** to uncover trends in:
- Job roles and salaries
- Work-life balance and salary satisfaction
- Entry difficulty into the data industry
- Demographics and programming language preferences

The goal of this project was to design a **clear, professional, insight-driven dashboard** suitable for business stakeholders and hiring managers.

---

## Key Insights
- **High salaries do not translate to high satisfaction**  
  Average salary satisfaction is **4.3 / 10**, despite competitive pay across senior roles.

- **Work-life balance remains a concern**  
  Average work-life balance satisfaction is **5.7 / 10**, indicating moderate dissatisfaction.

- **Data Scientist roles earn the highest average salary**, followed by Data Engineers and Architects.

- **Python dominates** as the most popular programming language by a large margin.

- **Breaking into the data industry is perceived as difficult**, with a majority reporting neutral to high difficulty.

---

## Dashboard Features
- KPI cards for key metrics (respondent count, average age, satisfaction scores)
- Salary comparison by job title
- Respondent distribution by country
- Programming language popularity
- Industry entry difficulty perception
- Interactive job title filter
